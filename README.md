# 秋招投递管理助手

一个轻量、离线运行的秋招投递管理工具。它使用 Python 自带的本地 Web 服务和 SQLite 数据库，不需要安装前端框架，也不会把投递数据上传到互联网。

项目自带一份**完全虚构的示例数据**，方便首次打开时了解公司、岗位、Base、部门和独立流程等功能。正式使用前可以直接删除示例单位。

## 主要功能

- 一个单位下管理多个岗位
- 分别记录 Base（城市）、部门和岗位名称
- 公司统一记录投递状态、当前阶段、笔试时间和面试时间
- 单个岗位可以覆盖公司的阶段、笔试时间和面试时间
- 支持展开与折叠公司
- 支持拖动调整公司和公司内部岗位顺序
- 支持搜索和按流程阶段筛选
- 支持保存官网或岗位投递链接
- 支持导出 Excel 备份

## 环境要求

- Python 3.10 或更高版本
- 任意现代浏览器
- 不需要 Node.js、数据库软件或额外的 Python 第三方依赖

## 下载与安装

### 方法一：下载 ZIP

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**。
2. 解压下载的压缩包。请保留完整目录结构，不要只复制 `app.py`。
3. 按下面对应系统的方式启动。

### 方法二：使用 Git

```bash
git clone https://github.com/Narzissenkreuz-Zhang/autumn-job-tracker.git
cd autumn-job-tracker
```

## 启动与本地部署

### Windows

1. 下载并解压整个项目文件夹。
2. 确保电脑已安装 Python 3（建议 Python 3.10 或更高版本）。
3. 双击 `启动秋招助手.bat`。
4. 浏览器会自动打开管理页面。
5. 使用结束后，关闭黑色命令窗口即可停止程序。

如果双击后提示没有找到 Python，请先从 [Python 官网](https://www.python.org/downloads/) 安装 Python 3。安装时建议勾选 **Add Python to PATH**。

### macOS / Linux

打开终端并进入项目目录，然后运行：

```bash
python app.py
```

默认地址为 <http://127.0.0.1:8765>。如果该端口已被占用，程序会自动尝试后续端口。

这个项目默认是单机本地工具：程序只监听 `127.0.0.1`，适合个人在自己的电脑上使用。它没有账号系统，不建议未经改造直接部署到公网服务器。

## 基本使用方法

1. 点击右上角“新增单位”，填写公司名称、统一进度和时间。
2. 展开公司后，点击“添加岗位”，填写 Base、部门和岗位名称。
3. 如果某个岗位的流程与公司整体不同，可在岗位中单独填写状态、笔试或面试时间；留空则自动跟随公司。
4. 使用顶部搜索框和阶段按钮快速筛选记录。
5. 在没有公司展开时，可以拖动公司左侧把手调整公司顺序；公司展开后，可以拖动其内部岗位调整岗位顺序。
6. 定期点击“导出 Excel”保存备份。

## 数据保存位置

- `data/autumn_jobs.db`：全部单位和岗位数据
- `exports/`：通过页面“导出 Excel”生成的备份

数据只保存在本机。需要迁移到另一台电脑时，复制整个项目文件夹即可；也可以定期使用“导出 Excel”保存备份。

## 开始记录自己的秋招

首次打开时会看到“示例银行”和几个示例岗位：

1. 展开示例单位，查看多个岗位的组织方式。
2. 点击单位或岗位右侧的“编辑”，体验流程继承和单岗位覆盖。
3. 熟悉后删除示例单位。
4. 点击右上角“新增单位”，开始录入自己的投递。

一般建议把同一家公司的统一笔试时间和总体进度写在公司层级；只有某个岗位的流程不同时，才在岗位编辑窗口中填写覆盖值。

## 隐私说明

- 项目内的示例名称、岗位、日期、网址和备注均为虚构内容。
- 程序只监听本机地址 `127.0.0.1`，不会主动上传数据。
- 首次启动只会尝试读取项目目录内的 `秋招投递管理表.xlsx`，不会扫描桌面或其他个人目录。
- 请勿将自己使用后的 `data/autumn_jobs.db`、导出的 Excel 或其他个人投递信息提交到公开仓库。

## 上传 GitHub 前的提醒

仓库已经通过 `.gitignore` 忽略运行缓存、导出的 Excel 和临时数据库文件。仓库中保留的 `data/autumn_jobs.db` 只是公开示例数据库。

如果以后想把已经录入真实信息的本地版本同步到 GitHub，请先确认提交内容中没有个人数据。
